# Canucks Men's Hockey League (CMHL)

Website for a Niagara-based recreational hockey league, displaying schedules, scores, standings, and stats.

## Tech Stack

- React, Next.js, Tailwind CSS
- Google Sheets API for live data updates
- Deployed via Vercel

## Features

- Reusable, modular, component-based code
- Read integration with Google Sheets API
- Dynamic league data display
- Responsive design for mobile and desktop
- Use of basic React hooks and state management
- Dynamic routing to display match up specific data, like boxscore and player stats
